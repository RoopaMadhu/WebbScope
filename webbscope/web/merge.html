Merge several datasets

Processed datasets (project folders with a matrix and cell metadata, or .h5ad files) are merged into one project to browse together. Each dataset is read as when it is opened alone. In the merged project the cell types, states, regions and other labels are kept as they are, the genes are those every dataset has, the cell ids get the dataset's name in front, and a sample name used by two datasets gets it too. Raw counts are log-normalised together; embeddings are not merged (each was computed on its own). The datasets are never modified. ← start page
