Import Xenium output

Turns a Xenium output bundle into a WebbScope project. Only the counts, cell table, cell boundaries and the 10x analysis files are read, plus the transcripts and an H&E scan if you ask for them; the Xenium images are never touched. ← open an existing project

1 · Xenium output

or give the files separately (override / complete the above)
H&E slide scan (optional, a separate file from the Xenium output; works with the .tar.gz / .zip too)

The scan is tiled and shown in the viewer's “H&E slide” window. It is not aligned to the Xenium coordinates (yet): it is shown as the scanned slide, with the annotations drawn on it.

Registered H&E images (optional): one .ome.tif / .ome.tiff per tissue, already in the Xenium frame

They are shown under or beside the cells (the Images button), unlike the slide scan above. Each image goes to the tissue whose name is the image's file name (without _warped_he.ome.tif); with an index.json the names can be anything. The tissues here are called tissue_1, tissue_2 … by the tissue detection, so an index.json is usually needed. The images are tiled into the project folder after the conversion.
